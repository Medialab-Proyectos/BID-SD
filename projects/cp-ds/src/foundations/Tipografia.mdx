# Tipografía

Una sola familia: **Open Sans**, con tres pesos: Regular (400), SemiBold (600) y Bold (700).
Clase de utilidad: `ds-text ds-text--{escala}[-{peso}]`. En los componentes de Material la
tipografía ya llega por el tema (Open Sans, pesos 400/600/700).

### Qué pesos existen por escala (verificado contra Figma, nodo `1:23`)

No todas las escalas tienen Regular + SemiBold + Bold: Figma define los pesos que se listan acá. En **Title**, la página de Tipografía solo muestra Regular, pero los componentes
usan las variantes SemiBold/Bold indicadas (verificado en cada nodo); la librería expone solo esas.

| Escala | Pesos en Figma |
|---|---|
| `display-lg` / `display-md` / `display-sm` | Regular, SemiBold, Bold |
| `headline-lg` / `headline-md` | Regular, SemiBold |
| `headline-sm` | Regular, SemiBold *(sin Bold)* |
| `title-lg` | Regular; **SemiBold** (Drawer-Header) |
| `title-md` | Regular; **SemiBold** (MiniCard) y **Bold** (Dialog, CardTitle, sub-header) |
| `title-sm` | Regular; **SemiBold** (cabecera de Table) |
| `label-lg` | Regular, SemiBold, Bold |
| `label-md` | Regular, SemiBold *(sin Bold)* |
| `label-sm` | **Solo Regular** |
| `label-xs` | **Solo SemiBold** (`ds-text--label-xs-semibold`; lo usan los Chips x-small) |
| `body-lg` / `body-md` | Regular, SemiBold, Bold |
| `body-sm` | **Solo Regular** |

`display-sm` además lleva `letter-spacing: 0.8px` (las demás escalas van en 0).
